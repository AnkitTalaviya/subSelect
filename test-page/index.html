SubSelect test pages

Synthetic players, so everything can be verified without depending on any third-party site. The first two cover the two subtitle sources; the rest reproduce the awkward shapes real players use, each of which has broken detection at some point.

  • Player-rendered DOM captions — GenericDomAdapter
  • Browser-rendered TextTrack cues — TextTrackAdapter
  • YouTube-style auto-generated captions — a player-sized caption container, and text that grows word by word
  • YouTube-shaped player — the caption window is removed between lines rather than emptied, rebuilt per cue, and "watch next" swaps the video without a page load
  • Netflix-shaped player — a full-frame caption layer whose text container is replaced on every cue, positioned with inline styles

Opened from disk? Chrome does not run any extension on a file:// page until you switch on Allow access to file URLs for SubSelect at chrome://extensions → SubSelect → Details. It is off by default, and with it off nothing here will respond to a click — the extension is simply not there.

The alternative is to serve this folder over HTTP — for example npx serve test-page — and then press Enable on this site in the SubSelect toolbar popup.

Both pages show a diagnostics panel that says whether the page is working and whether SubSelect has attached. The toolbar popup also reports what the engine sees on the current page. For detection logs, run localStorage.SUBSELECT_DEBUG = '1' in the console and reload.
