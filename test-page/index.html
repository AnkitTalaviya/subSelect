SubSelect test pages

Two synthetic players, one per subtitle source, so Phase 1 can be verified without depending on any third-party site.

  • Player-rendered DOM captions — GenericDomAdapter
  • Browser-rendered TextTrack cues — TextTrackAdapter

Opened over file://, these pages need Allow access to file URLs enabled for SubSelect on chrome://extensions. Otherwise serve the folder over HTTP and use Enable on this site in the SubSelect popup.

Run localStorage.SUBSELECT_DEBUG = '1' in the console and reload to see the engine's detection decisions.
