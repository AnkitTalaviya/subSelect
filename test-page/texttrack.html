SubSelect test — browser-rendered TextTrack cues

Exercises TextTrackAdapter. Cues are added with addTextTrack + VTTCue — no file, no CORS. The browser would normally render these in a shadow tree no extension can reach, so SubSelect switches the track to hidden and draws the caption itself. Click, drag and Ctrl/Cmd+C work here exactly as on the DOM-caption page. Turning SubSelect off must hand the track straight back to showing.
